# 异常排查手册（x-timeline）

## 采集脚本退出码

| 退出码 | 含义 | 处理 |
| ------ | ------ | ------ |
| 0 | 窗口闭合，采集成功 | 进入处理层 |
| 3 | 窗口未闭合（有数据） | 可用，但文内必须标注实际覆盖时长；连续两天未闭合需排查 |
| 2 | 需人工登录 | Chrome 窗口已保持打开，人工登录后重跑；**禁止自动输入凭据** |
| 4 | 风控/验证码拦截 | 停下等人工；连续 2 天命中则降低运行频率至隔日 |
| 1 | 其他错误 | 看 stderr 日志与截图存证，按下方对照表排查（含无法确认「正在关注」Tab、页面加载超时） |

## 常见问题对照表

| 症状 | 原因 | 修复 |
| ------ | ------ | ------ |
| Chrome 启动失败 | profile 锁文件残留 | 脚本已自动清理 `SingletonLock/Socket/Cookie` 并重试一次；仍失败则手动检查是否有其他进程占用该 profile |
| 打开后停在登录页 | 登录态过期 | 在打开的 Chrome 窗口手动登录 X，然后重新运行脚本 |
| 页面正常但拦截不到任何 GraphQL 响应 | 接口路径/签名变化，或页面未真正加载时间线 | 脚本会自动降级 DOM 兜底路径；若兜底也空，截图存证并检查网络与控制台报错 |
| 一直滚动但条目数不增长 | 被限流或到达账号时间线底部 | 连续 3 次空页自动停止；若 raw JSON 的 `closed_reason=timeline_exhausted` 则是时间线穷尽，属正常闭合 |
| 中止：无法确认「正在关注」Tab | Tab 结构变更或点击失效，为避免误采「For you」主动中止 | 人工在浏览器切到「正在关注」后重跑；连续出现则更新脚本选择器 |
| 条目时间解析全部失败 | `legacy.created_at` 结构变化 | 检查脚本常量区 `FIELD_PATHS`，对照一次真实响应 JSON 修正字段路径 |
| 文章被 Hugo 构建排除 | frontmatter `date` 晚于构建时间（未来页面） | `date` 改为写入时刻 − 5min；见 SKILL.md frontmatter 硬性规则 |
| 定时失败 | 网络/登录态/Chrome 问题 | 30 分钟后自动重试 1 次；二次失败仅报告、不产出文章，避免空窗假象 |
| 24h 内零条有效内容 | 关注列表当天确实无符合条件内容 | 仍生成文章如实报告「今日无符合条件内容」，不硬凑 |

## 降级决策树

```
GraphQL 拦截连续失败（空响应/结构无法解析 ≥3 次）
  ├─ 自动降级 DOM 滚动兜底路径
  │    ├─ 兜底成功（窗口闭合或未闭合）→ 产出 raw，标注路径与窗口状态
  │    └─ 兜底也失败 → 退出码 1，截图存证，报告用户
  └─ 双路径连续 2 天失效 → 评估改用官方 X API 或手动导出（见设计文档 §10.1）
```

## 排查辅助产物

- raw JSON：`.workbuddy/tmp/x-digest/raw-YYYY-MM-DD.json`（逐页增量落盘，崩溃不丢已采部分）
- 截图存证：`.workbuddy/tmp/x-digest/evidence-YYYY-MM-DD.png`
- 指纹库：`.workbuddy/tmp/x-digest/seen-post-ids.json`（滚动保留 90 天）
