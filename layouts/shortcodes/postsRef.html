{{- /* postsRef: 站内跨文章引用 shortcode。 用法： {{< postsRef "mathematical-foundations-deep-learning-agi-chern-simons" >}} {{< postsRef "quant-weak-signal-aggregation-and-signal-factory" "弱信号聚合与信号工厂" >}} 参数 1：目标文章的 URL slug（frontmatter 里的 slug，或文件名）。 参数 2（可选）：链接显示文本，缺省用 slug。 依据 DRY：URL 是派生数据，本 shortcode 按 slug 定位文章并用 Hugo 生成 RelPermalink，section 自动带上，杜绝手拼 URL 导致断链。 target 不存在 -> errorf 让构建失败；命中多条 -> 报歧义错误。 注：trim 必须用位置传参 trim (.Get 0) "/"；写成 `| trim "/"` 会把 "/" 当字符串、slug 当 cutset，导致恒等于 "/"（2026-08-19 教训）。 */ -}} {{- $slug := trim (.Get 0) "/" -}} {{- $text := (.Get 1) | default $slug -}} {{- $target := "" -}} {{- $count := 0 -}} {{- range site.RegularPages -}} {{- $cand := .Params.slug | default .File.ContentBaseName -}} {{- if eq (string $cand) $slug -}} {{- $count = add $count 1 -}} {{- $target = .RelPermalink -}} {{- if gt $count 1 -}} {{- errorf "postsRef[%s]: slug 命中多篇文章，请为文章标注唯一 slug" $slug -}} {{- end -}} {{- end -}} {{- end -}} {{- if not $target -}} {{- errorf "postsRef[%s]: 在文章列表里找不到该 slug，请核对 frontmatter slug 或文件名" $slug -}} {{- end -}} {{ $text }}
