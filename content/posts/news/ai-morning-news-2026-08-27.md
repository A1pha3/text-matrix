### 智谱开源 GLM-5.3 Flash，「牛来」模型真身曝光
来源: 量子位
原文: [原文](https://www.qbitai.com/2026/08/479919.html)
摘要: 连日来在网上走红的神秘模型「牛来」（Ox Alpha）被确认出自智谱，即刚发布即开源的 GLM-5.3 Flash，也是 GLM-5 系列首个原生多模态模型。官方数据显示，320B 参数的 GLM-5.3 Flash 在能力上全面超越 753B 的 GLM-5.2，在 AA 榜单拿下 57 分、与 Claude Opus 4.8 持平；定价为 GLM-5.3 的 1/10，限时折扣下低至 Opus 4.8 的 1/40。据称其训练所用 62T tokens 全部跑在国产芯片上。

### 阿里千问 Qwen3.8-Flash 发布并开源，激活 60 亿参数对标前沿性能
来源: 36氪
原文: [原文](https://m.36kr.com/newsflashes/3956345253084296)
摘要: 8月26日，阿里发布并同步开源千问最新模型 Qwen3.8-Flash。该模型采用新一代架构，千亿总参数仅激活 60 亿（6B）即可获得超越 Claude Opus 4.6 的前沿性能，训练成本较 Qwen3.7-Plus 骤降近 90%，推理成本同步大幅下降，每百万 Tokens 输入 1 元、输出 3 元，价格最低至 DeepSeek-V4-Flash 的 1/3。当晚将首发上线「千问办公」，开发者和企业可通过千问 AI 平台获取 API 服务。

### Google DeepMind 推出 Gemini 3.5 Transcribe，主打智能实时转录
来源: Google DeepMind
原文: [原文](https://deepmind.google/blog/intelligent-transcription-with-gemini-3-5-transcribe/)
摘要: DeepMind 发布其目前最精确的语音转文字模型 Gemini 3.5 Transcribe，宣称相比传统语音识别更能应对背景噪声、专业术语与口语赘词，可把原始音频直接转成规范、带格式的文本。该模型通过两条 API 提供：Live API 面向亚秒级低延迟的双向流式场景，Interactions API 面向录音、会议与通话记录处理，支持说话人归因与词级时间戳，已在 Gemini API、Google AI Studio 与 Gemini Enterprise Agent Platform 开放。
