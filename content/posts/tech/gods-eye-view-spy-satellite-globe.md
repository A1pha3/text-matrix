## 一句判断

开源情报（Open Source Intelligence，OSINT）的瓶颈从来不是数据匮乏，而是界面：信号散落在几十个浏览器标签页里，聚合靠人肉。God's Eye View 把这件事做成了一张可交互的 3D 地球——航班、船舶、卫星、地震、公共摄像头实时铺在地球上，浏览器里直接跑，不需要密钥也能启动。

这个项目把"看起来像电影里的军用 HUD"和"每一行代码都能查"两件事叠在了一起。前者是体验，后者是它作为开源项目的底气。

## 它到底是什么

God's Eye View 是一个运行在浏览器里的地球可视化应用，作者 bilawalsidhu 凭借同名 YouTube 系列走红（README 称累计播放量超 500 万）。2026 年 8 月底开源，一周内冲到 GitHub Trending 第一，目前约 1.6 万 stars。

它的数据不是模型渲染出来的假数据，而是真实公共信号：

- **航班**：来自飞机应答机（ADS-B）广播的实时航迹
- **船舶**：船载信标（AIS）的位置报告
- **卫星**：轨道根数（TLE）推算的空间目标位置
- **地震**：地震台网发布的事件
- **公共摄像头**：接入公开的城市摄像头画面

渲染底座是 Cesium（WebGL 三维地球引擎），叠加了作者自研的实时信号流、检测网格与传感器风格层。

## 上手：两条路径

项目对安装做了明显让步——README 明确写"无密钥、无注册、无配置文件"。

**路径一：Pinokio 一键安装**。在 Pinokio 里粘贴仓库地址，点 Install 再点 Start 即可，适合不想碰终端的用户。

**路径二：终端 / coding agent**。需要 Node.js 24.14.x 或 26.x：

```bash
npm install
npm run doctor
npm run dev
```

打开 `http://localhost:4173`。README 给出的冷启动基线约 2 秒（M5/Chrome 实测中位数，属于对照基线而非硬件要求）。

首次启动会弹一张"任务卡"，让你选择 **Live Contacts**（实时联系目标）、**Space Missions**（太空任务）或 **Environmental**（环境数据），也可以直接手动探索。

## 核心能力速览

项目最出彩的几个交互，README 都配了 GIF 演示：

- **驾驶舱视角**：锁定一架在飞航班后切进 Cockpit，镜头跟着飞机走，地形始终压在机身下方，途中可以切换传感器模式。
- **点击追踪**：点任意目标，镜头锁定、画出渐隐航迹、弹出完整元数据卡；正在燃烧的火灾或船只可以一键转交给最近的公共摄像头。
- **语音白板**：对地球说话，把边界多边形、标记、路线实时标注上去（需要 OpenAI 密钥）。
- **3D 机库**：按机型加载真实 3D 模型（787、ATR-72、MQ-9 等），追踪目标靠近后从图标切换成模型。
- **传感器滤镜**：`1`–`7` 数字键切换 CRT、夜视（NVG）、FLIR 热成像、黑白等 GLSL 风格，整个地球重新渲染。
- **检测叠加**：屏幕空间边界框 + ID，框住视野内每个目标。
- **分享链接**：相机姿态、风格、图层甚至追踪目标都序列化进 URL——一个活的目标是"交接"，不是"书签"。

## 数据真实边界：哪些是实况，哪些是估计

这一点值得单独说，因为 README 自己做了区分，写文章不能含糊：

- **真实且实时/准实时**：航班、船舶、卫星、地震、公共摄像头。
- **模拟或粗略估计**：道路交通是沿真实道路、用聚合位置数据模拟的；公共摄像头的相机位姿和火箭发射轨迹是粗略估计。

换句话说，这不是一个"全真"的地球——**信号是真的，但视觉呈现里掺了模拟成分**。把它当军用级实时态势系统用，会高估它的能力；把它当"公共信号的可视化教学台 + 交互演示"来理解，则恰到好处。

## 密钥与成本：不花钱能到哪一步

无密钥状态即可看到：无密钥的 Esri 全球影像 + 地形，以及已在运行的基本图层；Esri 不可达时 OSM 自动兜底。开源情报该有的"开箱即用"它做到了。

想要更强的效果，在应用右下角的 **POWER UP** 面板按需配置：

| 密钥 | 打开什么 | 说明 |
|------|----------|------|
| Cesium ion（免费档） | 写实 3D 城市与全球地形 | 个人非商业用途免费，按当前条款与配额 |
| Google Maps | 计费启用的影像 + 应用内地点搜索 | 有较慷慨的免费档 |
| OpenAI | 语音控制与语音白板 | 想"跟地球说话"时再配 |

密钥存进 `.env`（终端克隆）或 `pinokio/ENVIRONMENT`（Pinokio），写入前会设为仅属主可读，且不会离开本机。服务器只绑定 localhost，Provider Settings 只响应本机请求；浏览器端密钥（Google Maps / Cesium）需要按提供方要求做域名限制，README 的 SECURITY.md 有说明。

## 适用边界

**适合**：OSINT 爱好者当可视化教学台；做地理空间可视化的开发者当 Cesium + 实时数据流集成的参考实现；对"真实信号 × 3D 呈现"感兴趣的技术读者。

**不适合**：需要军事级实时态势精度的工作场景（数据有模拟成分）；需要商用授权能力确认的场景（项目许可为自定义 Other，未挂标准开源协议，商用前需自行核实条款）。
