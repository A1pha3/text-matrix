## Freebuff 是什么

[Freebuff](https://github.com/CodebuffAI/freebuff) 是 CodebuffAI 开源的免费 AI 编程智能体，仓库简介只有一句——"The free coding agent"。它的核心卖点是：**不需要订阅、不需要充值积分、也不需要自备 API Key**，就能用上一排主流模型来写代码，支撑这一切的是文字广告，而不是用户付费。

对于被"AI 编程工具月费"支配的开发者来说，这个项目值得认真看一眼：它既是一个能直接用的工具，也是"免费 AI 服务如何可持续"这个命题的一次工程实践。

先给两个动手前需要知道的判断。第一，这个项目的模型目录和免费政策变动极快——本文 8 月发表时主推的 GPT-5.6 Luna、DeepSeek V4 Pro、MiniMax M3，到 10 月已经全部退役或换名，免费额度机制也从"每天 N 个会话"换成了货币制。看模型清单之前，先看它怎么变。第二，你在 GitHub 上看到的仓库并不是开发一线：CONTRIBUTING.md 开头写明，这是 "a public mirror of the Freebuff/Codebuff source tree"——私有仓库才是源码真身，公开仓库是单向导出的镜像，提交的 PR 即使被接受也不会在这里合并，而是被维护者搬进私有仓库、随下一次导出回来。这解释了为什么它的提交记录清一色是 "Sync public snapshot from freebuff-private"。

规模与节奏：截至 2026 年 10 月 4 日，仓库 13,150★、1,404 forks（8 月下旬发文前后约 10,400★），Apache 2.0 协议，TypeScript 编写，Bun 构建。它确实迭代极快，但快的不是 GitHub Releases——Releases 页面停在 2025 年 10 月的 v1.0.420-beta.185（名称还挂着旧名 "Codecane"）；版本推进实际发生在两处：git tag 已经走到 v1.0.679，npm 包 `freebuff` 则从 3 月首发的 0.0.1 一路发到 10 月 3 日的 0.2.13，197 个版本，几乎日更。

## 五种产品形态：一个内核，多端覆盖

Freebuff 不只是一个 CLI 工具，而是一个产品矩阵，覆盖了开发者的几乎所有工作场景：

| 产品 | 定位 | 适用场景 |
|------|------|----------|
| **Freebuff CLI** | 终端编程智能体 | 任意项目目录内直接跑 agent |
| **Freebuff Desktop** | 本地桌面应用 | 并行跑多个 agent，各自隔离工作区 |
| **Freebuff Web** | 浏览器全栈构建 | 从零搭建并部署完整应用 |
| **Freebuff Cloud** | GitHub 仓库托管 agent | 给任意 GitHub 仓库挂上 agent |
| **Freebuff Chat** | 对话与研究 | 技术调研、方案思考 |

最轻量的入口是 CLI，两条命令就能跑起来：

```bash
npm install -g freebuff
cd ~/my-project
freebuff
```

之后直接用自然语言描述你要做什么，Freebuff 会自动定位相关文件、做出修改、并运行项目适用的检查。

值得一提的是 Desktop 版还有一个进阶能力：它可以接管本地已安装的 Claude Code 和 Codex，让你继续用自己已有的 provider 账号——Freebuff 自带的免费模型目录与这些"连接模型"是并存的两套体系，互不干扰。

## 多智能体架构：不是"一个模型一个提示词"

Freebuff 底层构建于 Codebuff 之上——README 对它的定位是 "the open multi-agent framework"，负责编排、工具和 SDK（npm 包 `@codebuff/sdk`，当前 0.10.7）。它没有采用"把所有任务塞给同一个模型"的做法，而是按任务类型分派给专职 agent：

- **代码库上下文 agent**：在动手改代码之前，先用文件查找类 agent 摸清项目结构，定位真正相关的文件；
- **实现与审查 agent**：可以拆分工作、并行修改、执行命令、检查结果；
- **研究与浏览器 agent**：能查文档、在真实浏览器里测试应用。

用一次典型的 CLI 会话把这些机制串起来。假设你要修一个登录报错：输入描述后，文件查找 agent 先扫出鉴权相关的几个文件，把上下文交给实现 agent；实现 agent 改完代码跑测试，如果项目配置了 lint 或类型检查，检查命令也会被触发；结果回给审查环节确认改动是否完整。桌面端还能把这个过程拆成多份并行——比如同时让两个 agent 在各自隔离的工作区里试两种修法。这套流程里你只做一件事：描述问题。

这种"专职 agent 分工"是免费模式能撑住成本的关键之一：文件查找、资料检索这类高频轻任务交给专司此事的小模型，不占用主选择器入口——目前干这活的是 Gemini 3.1 Flash Lite。重活留给用户自己选的模型，token 预算各归其位。

## 模型目录：一个半月换了一轮血

这是本文发表后变化最大的部分，也是观察这个项目最好的窗口。

## 免费模式的边界：你需要知道的事

免费不等于无条件。访问分层设计在 10 月也换了一版：

- **完整访问**：受支持地区的用户可用上表全部模型；
- **受限访问**：其他地区和 VPN 用户可用六款模型（GLM 5.3 Flash、DeepSeek V4.1 Flash、MiMo 2.6 Flash、Solar Mini 4、Solar Pro 4、Space Bunny Alpha），额度改为 **Freebucks 货币制**——每个模型按选择器里的标价扣费，每天免费 25 Freebucks（VPN 或代理环境 20），先花免费额度再花赚取的；推荐和 bounty 任务可以赚额外的量；
- **数据使用**：只有模型或功能明确标注"数据可能用于 AI 训练"时，提交内容才会被用于训练。服务方可能分析提示词和消息用于广告个性化，但单独上传的文件和连接的仓库不会提供给广告商——受限合作伙伴可以评估连接的 Cloud 仓库，但不能使用、广泛分享或拿去训练。

8 月时的规则是"受限用户每天 3 个一小时 MiMo 2.5 会话，可赚取到 7 个"，如今连计量单位都换了。换句话说，免费的代价始终是"看广告 + 部分数据可能被用于训练/广告分析"，但具体给多少、怎么算，官方保留随时重写的权利——把它当长期基础设施依赖之前，先想清楚这一点。对涉及敏感代码的商业项目，数据条款需要逐条评估；对个人学习、开源贡献、快速原型，这个取舍大多数人是可以接受的。

## 工程实现一览

对想读源码或贡献代码的人，仓库结构信息量不小：

- **技术栈**：TypeScript monorepo，Bun 作为运行时和包管理器（当前钉在 1.3.14）；
- **目录划分**：`agents/`（智能体定义）、`cli/`（命令行）、`sdk/`（SDK）、`packages/`（共享包，含 agent-runtime、code-map、llm-providers 等）、`evals/`（评测）、`docs/`（文档）等，模块边界清晰；
- **本地开发**：需要 Docker 和配置好的 `.env.local`，`bun install && bun up` 启动服务，`bun start-cli` 单独跑 CLI；
- **贡献流程**：因为公开仓库只是镜像，PR 被接受后由维护者搬进私有仓库、随下一次导出回来，所以"改动是否值得搬运"比"是否干净合并"更重要。每个 PR 打开后约十秒内会跑三道结构性检查并触发一个自动审查。

有意思的是仓库根目录放了 `AGENTS.md`——这个文件是给 AI 编程智能体看的项目说明，Freebuff 自己就是 AI agent 工具，用 AGENTS.md 指导 agent 参与自家开发，算是"吃自己的狗粮"。

## 谁该用、谁该等等

**适合现在就试的人**：

- 不想为 AI 编程工具付月费的个人开发者——完整访问下五款不限量模型，日常改码基本够用；
- 想在终端里快速挂一个免费 agent 处理日常任务的极简主义者，两条命令即可起步；
- 研究多智能体编排、想在 Codebuff 框架上做二次开发的人——`@codebuff/sdk` 和 `agents/` 目录是现成教材。

**需要观望的人**：

- 对代码隐私和训练条款敏感的团队——先读完 Privacy Policy，特别留意"受限合作伙伴可评估连接的 Cloud 仓库"这条新边界；
- 需要稳定模型清单和配额规则的生产环境——一个半月内模型整表换血、计量制重写，说明免费策略仍在高频试错期；
- 期望社区驱动开发的人——这里是单向镜像，没有真正的公开协作面。

从小处入手是合理的路径：先用 CLI 在一个不敏感的个人项目上跑几天，观察它的会话限流和数据提示，再决定要不要把更多工作流交出去。

## 小结

Freebuff 用"广告养模型"的思路，把一排旗舰模型的编程能力做成了零门槛工具，多端形态覆盖了从终端到云端的完整链路。它最值得看的其实不是某个具体模型，而是这套机制本身：私有仓库单向导出的镜像式开发、按任务分派的专职 agent、以及一个一个半月就重写一遍的免费经济学。用之前想清楚自己拿它写什么代码、愿意交出什么数据，比什么都重要。
