# Anthropic 官方 Claude 课程与认证全览：22 门免费课程、4 门认证考试

Anthropic 把自家的学习内容集中放在官方平台 [anthropic.skilljar.com](https://anthropic.skilljar.com)（页面标题就是 "Anthropic courses"）。截至 2026 年 9 月 21 日，这里共有 **22 门免费课程**，从 Claude 日常使用一路讲到 MCP 进阶与云上部署；另设 **4 门 Claude 认证考试**，面向 Anthropic 合作伙伴，考试收费（99–175 美元），备考课程免费。课程均为英文授课，注册账号即可自学。

官方课程里有一句产品分工的口诀：Chat 负责思考，Cowork 负责委托，Code 负责软件。下面按这条线索整理全部课程。

## 认证考试

课程之外，Anthropic 还运营一套 [Claude 认证体系](https://anthropic-partners.skilljar.com/page/partner-certifications)，按角色分为 Associate（面向顾问、销售、交付负责人）、Developer（面向用 API、Claude Code、MCP 做集成的工程师）、Architect（面向端到端设计 Claude 方案的架构师）三个方向，每门先考 Foundations，Architect 方向另有 Professional 进阶。认证页明确写着面向 Anthropic 合作伙伴，非合作伙伴需要先申请加入；其中 Associate 认证不计入 Claude Partner Network 的等级评定。

| 认证 | 角色 | 费用 | 题量 / 时长 |
|------|------|------|------------|
| [Claude Certified Associate – Foundations](https://anthropic-partners.skilljar.com/claude-certified-associate-foundations-certification) | Associate | $99 | 60 题 / 120 分钟 |
| [Claude Certified Developer – Foundations](https://anthropic-partners.skilljar.com/claude-certified-developer-foundations-certification) | Developer | $125 | 53 题 / 120 分钟 |
| [Claude Certified Architect – Foundations](https://anthropic-partners.skilljar.com/claude-certified-architect-foundations-certification) | Architect | $125 | 60 题 / 120 分钟 |
| [Claude Certified Architect – Professional](https://anthropic-partners.skilljar.com/claude-certified-architect-professional-certification) | Architect | $175 | 63 题 / 120 分钟 |

四门考试的共同口径：题型为单选加多选，通过分 720（标度 100–1000），线上监考或 Pearson 考试中心两种方式，考试语言英语，证书有效期 12 个月。备考不另收费：Associate、Developer Foundations 与 Architect Professional 三门配有专属免费备考路径，Architect Foundations 给出的是七门课的备考组合，全部出自上面的课程目录，例如 Developer Foundations 就对应 Building with the Claude API、Claude Code in Action 与 MCP 入门三门。

## 推荐学习路径

- **日常使用者**：Claude 101 → AI Capabilities and Limitations → Introduction to Claude Cowork → AI Fluency: Framework & Foundations
- **开发者**：Building with the Claude API → Claude Code 101 → Claude Code in Action → agent skills → subagents → MCP 入门与进阶 → 按需补 Bedrock 或 Google Cloud 部署课
- **备考认证**：按官方备考组合选课——Associate 考 AI 素养、Claude 101 加 Cowork 三门；Developer 考 API、Claude Code in Action 加 MCP 入门三门；Architect Foundations 组合最全，共七门课；Architect Professional 考 API、MCP 入门与进阶加两门云平台课
