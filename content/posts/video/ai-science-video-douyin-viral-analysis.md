### 2.2 抖音算法推荐机制

一条视频从发布到百万级曝光，经过这样一条链路：

```text
视频发布
    ↓
初始流量池（200-500曝光）
    ↓
根据完播率、互动率初步评估
    ↓
达到阈值 → 进入更大流量池（3000-10000）
    ↓
持续表现优秀 → 百万级曝光
    ↓
爆款视频 → 搜索流量持续涌入
```

### 2.3 抖音 vs B 站内容分发差异

| 维度 | 抖音 | B 站 |

### 3.2 令牌化设计系统

BiliSummary 采用了令牌化设计系统（Tokenized Design System），把颜色、间距、圆角都抽成 CSS 变量：

```css
:root {
  --color-primary: #00a1d6;
  --color-bg: #f4f5f7;
  --color-text: #18191c;
  --space-xs: 4px;
  --space-md: 16px;
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #1d1d1d;
    --color-text: #e8e8e8;
  }
}
```

改一处全局生效、深色模式只换变量值——这是令牌化设计最直接的好处，比在每处组件里硬编码 class 分支更不容易出错。

## 五、可复制要素清单

### 内容层面

选题追热点、用数据说话、引发共鸣；开头 3 秒定律——前 3 秒必须有钩子；结构采用总分总、清单式或故事线；结尾做总结加互动引导。

### 技术层面

字幕提取用 BiliSummary（ASR 降级）、视频下载用 bilibili-api-python、内容整理用 Markdown 加图片本地化、批量处理用 asyncio 并发任务、多平台同步发布。

### 运营层面

每周发布 2-3 条、回复评论建立粉丝粘性、定期复盘优化方向、关注 AI 圈动态跟踪热点。

## 六、常见误区

- **"复刻 = 把爆款视频抄一遍"**——可复制的是选题逻辑、结构模板和开头钩子，不是具体文案；照抄内容只会被算法当搬运。
- **"流量靠发布时间"**——决定能不能进下一个流量池的是完播率与互动率，不是发布时间本身。
- **"工具能替代选题"**——BiliSummary 这类工具提高的是整理与复盘效率，优质选题与表达依然稀缺。

## 收束

四件事值得记住。第一，AI 科普赛道机会大——AI 工具降低了创作门槛，但优质内容依然稀缺。第二，爆款有规律可循——结构化模板加热点追踪加 AI 提效，三件事踩中就能复制。第三，技术工具增强创作——BiliSummary 等工具让创作者更高效。第四，平台特性要适配——抖音、B 站策略各不相同，同一期内容应该针对不同平台做差异化剪辑。
