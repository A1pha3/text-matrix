# 隐私政策

本页说明 Text Matrix 在站点访问、内容展示、流量统计与广告投放过程中可能涉及的信息处理方式。

## 一、基本原则

本站以公开内容发布为主，不要求普通访问者注册账号，也不会主动要求你提交与阅读无关的敏感个人信息。

## 二、日志与基础技术信息

当你访问本站时，站点托管平台、CDN、浏览器与网络服务提供方可能会自动记录部分基础技术信息，例如：

- IP 地址
- 浏览器类型与设备信息
- 访问时间
- 访问页面与来源链接

这些信息用于安全防护、故障排查、性能优化和基础流量分析。

## 三、Cookie 与本地存储

本站或所使用的第三方服务可能会使用 Cookie、本地存储或类似技术，以支持以下功能：

- 记住主题模式等站点显示偏好
- 改善页面加载与使用体验
- 支持广告展示、频次控制与效果衡量

你可以通过浏览器设置限制或清除 Cookie，但这可能影响部分功能或广告体验。

## 四、流量统计服务

本站接入 Google Analytics 等流量统计服务，用于了解页面访问量、访问来源与内容的受欢迎程度，以此决定写作与改进方向。此类服务会通过 Cookie（如 `_ga` 前缀）收集匿名化的访问信息，不用于识别你的真实身份。

如需了解 Google 在合作网站中如何处理数据，可参考：https://policies.google.com/technologies/partner-sites

## 五、第三方广告服务

本站可能接入 Google AdSense 或其他第三方广告服务。此类服务会根据其自身政策收集和处理部分信息，用于：

- 展示广告
- 控制广告投放频次
- 评估广告效果
- 防止无效流量和欺诈行为

Google 等第三方供应商可能会使用 Cookie 或类似技术，根据用户此前访问本站或其他网站的记录提供个性化或非个性化广告。

如果你希望进一步了解 Google 如何使用数据，可参考 Google 的相关政策说明：

- https://policies.google.com/technologies/ads
- https://policies.google.com/privacy

## 六、外部链接

本站文章可能包含指向第三方网站、产品页面、开源仓库或文档的链接。你点击外部链接后，将受到对应第三方站点隐私政策与服务条款的约束，本站不对第三方站点的信息处理行为负责。

## 七、Giscus 评论

本站文章页可能嵌入 Giscus 评论组件。打开评论区时，浏览器会加载 `giscus.app` 和 GitHub 相关资源；评论内容存储在公开的 GitHub Discussions 中，不进入本站 Hugo 生成的页面或数据库。

如果你要发表评论，必须登录 GitHub，并首次授权第三方 Giscus GitHub App 代表你在本站绑定的公开 comments 仓库中发布。评论、回复、GitHub 用户名、头像和公开资料可能被其他人看到；请勿提交密码、联系方式或其他敏感信息。评论功能同时受 GitHub 与 Giscus 的条款和隐私政策约束。

评论的隐藏、删除、锁定和举报由 comments 仓库维护者依据仓库行为准则和 GitHub 规则处理。如需提出删除或隐私请求，请通过 [联系页面](../contact/) 提供原 GitHub 账号和具体 Discussion 链接；我们会在能够核验请求归属的范围内处理。

## 八、未成年人保护

本站面向一般技术读者，不以未成年人为主要受众。如你判断某些内容或信息处理方式不适合未成年人访问，请停止使用相关服务，并由监护人协助处理。

## 九、政策更新

本站可能根据法律要求、广告平台政策、产品功能或托管方式调整本隐私政策。更新后的内容会直接发布在本页，并自发布之日起生效。

## 十、联系与反馈

如果你对本隐私政策、内容勘误、版权问题或广告展示有反馈，可通过 [联系页面](../contact/) 查看当前可用的公开联系渠道。
